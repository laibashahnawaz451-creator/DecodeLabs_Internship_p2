## Java Student Grade Calculator

# Project Description

This is a simple Java console-based **Student Grade Calculator**.

The program asks the user to enter the number of subjects, followed by each subject's name and the marks obtained. It then calculates the **total marks**, **average percentage**, and displays the **overall grade** based on the average.

### Grade Criteria

* **90% and above** → Grade **A**
* **80% – 89%** → Grade **B**
* **70% – 79%** → Grade **C**
* **60% – 69%** → Grade **D**
* **Below 60%** → **Fail**

---

## Features

* User input using `Scanner`
* Accepts multiple subject names and marks
* Calculates total marks
* Calculates average percentage
* Displays overall grade
* Uses loops and conditional statements

* Scanner Class

## How to Run

1. Clone this repository:

   ```
   https://github.com/laibashahnawaz451-creator/DecodeLabs_Internship.git
   ```

2. Open the project in any Java IDE (VS Code, IntelliJ IDEA, Eclipse, etc.).

3. Compile the Java file:

   ```bash
   javac DecodeLabs_java_p2.java
   ```

4. Run the program:

   ```bash
   java DecodeLabs_java_p2
   ```

5. Enter the number of subjects, subject names, and marks to calculate the total marks, average percentage, and overall grade.
